# Ковчег

«Ковчег» — мобильная браузерная игра-прототип (ферма + лотерея) для Яндекс Игр: после апокалипсиса последние животные Земли разыгрываются в тиражах выживших, а ты собираешь их на своей ферме, строишь и чинишь вольеры, кормишь и лечишь животных вместе с командой героев (фермер, механик, ветеринар) и пытаешься собрать все 38 видов по 5 особей. Играть: https://vgametikok.github.io/ami-als_farm/
